# Grammar Lab

Interactive grammar practice for first-year linguistics students.

## Topic 1

Open `topic1/index.html` locally, or publish the repository with GitHub Pages to use:

`https://alyonazerg.github.io/grammar/topic1/`

### Enable GitHub Pages

In the repository: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save**.

The Topic 1 lab contains five modules:
- Noun X-Ray
- ’s or of?
- Possession Lab
- Article Logic
- Modifier Challenge

The site is plain HTML/CSS/JS and has no external dependencies.
